# Get SHT Out Website

Static launch site for `getshtout.com`, built as a quick case-study version of a junk removal business website.

## Files

- `index.html` - page content and SEO metadata
- `styles.css` - responsive layout and visual system
- `script.js` - quote form mailto handler
- `assets/hero-junk-removal.png` - generated hero image used by the landing page
- `assets/logo-mark.svg` - compact brand mark
- `assets/logo-horizontal.svg` - horizontal wordmark
- `BRAND_IDENTITY.md` - logo concept and usage notes
- `DEPLOYMENT.md` - deploy and cache-busting instructions
- `LOCAL_DEVELOPMENT.md` - first-time localhost setup guide
- `hosting-notes.md` - recommended hosting path and cloud-credit options

## Preview Locally

Open `index.html` in a browser, or run a tiny local server:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

For a first-time setup walkthrough, see [LOCAL_DEVELOPMENT.md](LOCAL_DEVELOPMENT.md).

## Deploy

For publishing changes to GitHub Pages, see [DEPLOYMENT.md](DEPLOYMENT.md).
